# Re:Start Quest QA 기준

QA는 구현자가 보고한 완료 여부가 아니라 실제 사용자 흐름과 재현 가능한 명령을 기준으로 판정한다.

## 필수 검증

- `회원가입 -> 온보딩 -> 퀘스트 3개 생성 -> 완료 -> 실패 이유 입력 -> 더 쉬운 행동 재설계 -> 대시보드 반영`
- 인증 만료, 중복 완료/재설계, provider 오류의 구분된 응답
- 재설계 후 새로고침해도 현재 퀘스트와 기록이 유지되는지
- 모바일과 데스크톱에서 핵심 UI가 겹치거나 잘리지 않는지
- 사용자 평가·감시·상담·진단 문구가 노출되지 않는지

PASS에는 실행 명령, 결과, 검증한 commit SHA를 남긴다. 환경 문제로 실행하지 못했다면 코드 결함과
환경 blocker를 분리하고, 확인하지 않은 항목을 PASS로 추정하지 않는다.
