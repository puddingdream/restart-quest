# Review remediation

1. QA와 Reviewer 결과를 최신 PR head 기준으로 수집한다.
2. 중복 지적을 묶고 blocker와 제안 사항을 분리한다.
3. blocker는 원래 구현 역할에 돌려 관련 호출 경로와 회귀 테스트를 함께 수정한다.
4. 수정 push 후 기존 thread에 해결 내용과 검증 명령을 남기고 최신 head 재검토를 요청한다.
5. 새 blocker가 없으면 merge 정책을 다시 평가한다.

같은 원인으로 두 번 실패하면 동일 명령만 반복하지 않는다. 세 번째 시도 전에 원인과 필요한 사람
작업을 기록하고, 외부 콘솔·권한·secret 설정이 필요할 때만 사용자에게 구체적인 단계로 요청한다.
