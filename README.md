# Re:Start Quest

실패한 구직 행동을 더 작은 행동으로 다시 시작하도록 돕는 MVP입니다.
이번 저장소는 AgentFlow가 요구사항만 있는 상태에서 설계, 구현, 검증, PR 전달까지 수행하는 실전 테스트에 사용합니다.

## 현재 상태

- 2026-10-09 새 테스트 기준선: 요구사항과 공통 작업 규칙만 있습니다.
- 제품 코드, 실행 환경, 설계 산출물, 통과한 제품 테스트는 아직 없습니다.
- 이전 실험의 PR, Issue, 브랜치, 보고서는 이번 구현의 입력이 아닙니다. 별도 백업에 보존했으며 자동 복원하지 않습니다.

## 시작점

1. [AGENTS.md](AGENTS.md)와 [프로젝트 브리프](docs/PROJECT_BRIEF.md)를 읽고 현재 추적 파일을 조사합니다.
2. 브리프의 MVP를 구현합니다. 새 제품 후보 선정이나 과거 구현 복원을 다시 시작하지 않습니다.
3. 기술 선택, 작업 분할, 역할 배정과 병렬 실행은 팀장과 팀원이 판단하고 이 저장소에 근거를 기록합니다.
4. 구현 후 이 README를 실제 설치, 실행, 테스트 명령과 남은 제약으로 갱신합니다.

이번 테스트의 전달 목표는 핵심 흐름이 동작하고 QA와 리뷰가 끝난 **통합 PR**입니다.
자동 머지와 외부 배포는 요청 범위에 포함하지 않습니다. 개별 작업이나 문서 작성만 끝내고 MVP 완료로 보고하지 않습니다.
