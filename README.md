# Re:Start Quest

실패한 구직 행동을 더 작은 행동으로 다시 시작하도록 돕는 로컬 MVP입니다. 사용 가능한 시간과 현재 상태로 규칙 기반 퀘스트를 만들고, 완료 또는 실패 이유를 기록한 뒤 더 쉬운 행동으로 이어갈 수 있습니다. 화면과 JSON API는 같은 Node.js 서버에서 제공하며, 기록은 파일에 저장됩니다.

제품 범위와 세부 계약은 [프로젝트 브리프](docs/PROJECT_BRIEF.md)와 [구현 계약](docs/IMPLEMENTATION.md)을 참고하세요.

## 실행

Node.js 20 이상과 npm이 필요합니다. 저장소 루트에서 실행합니다.

```sh
npm ci
npm start
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다. 서버는 기본적으로 `127.0.0.1`에만 바인딩합니다. 기본 저장 위치는 **명령을 실행한 작업 디렉터리**의 `data/restart-quest.json`입니다. 첫 기록을 저장할 때 디렉터리와 파일이 만들어집니다.

다음은 포트와 저장 파일을 바꾸는 비밀값 없는 POSIX 셸 예시입니다. 저장 기록을 Git에 추가하지 않도록 실제 사용 시에는 저장소 밖 경로를 지정하는 편이 안전합니다.

```sh
PORT=3100 RESTART_QUEST_DATA_FILE=/tmp/restart-quest-local.json npm start
```

이 경우 `http://127.0.0.1:3100`에서 접속합니다. `RESTART_QUEST_DATA_FILE`에 상대 경로를 쓰면 명령을 실행한 디렉터리를 기준으로 해석됩니다.

## 사용 흐름

1. 5~120분의 사용 가능한 시간을 입력하고 현재 상태를 선택해 **퀘스트 만들기**를 누릅니다.
2. 제안된 구직 준비 행동을 실행한 뒤 **완료하기** 또는 **실패 기록**을 선택합니다.
3. 실패했다면 이유와 선택적 메모를 저장합니다. 화면에서 더 작은 퀘스트 제안을 확인하고 **더 쉬운 퀘스트 만들기**로 확정합니다.
4. 새 행동을 실행하고 **다음 행동**과 **실행 기록**에서 완료·실패·재설계 관계를 확인합니다. 새로고침과 서버 재시작 후에도 확정된 기록을 다시 볼 수 있습니다.

가장 작은 단계에서 실패한 경우에는 더 줄일 퀘스트를 제안하지 않습니다. 새 퀘스트를 만들어 다시 시작할 수 있습니다.

## 테스트와 수용 검증

```sh
npm test
```

이 명령은 규칙 및 실제 HTTP·파일 저장 회귀 테스트를 실행합니다. 데스크톱과 375px 모바일의 실제 Chromium 흐름을 포함한 수용 검증 진입점은 다음과 같습니다.

```sh
node scripts/verify.mjs --playwright-module=/absolute/path/to/playwright/index.mjs --artifacts-directory=/absolute/path/outside/checkout/artifacts
```

두 경로는 절대 경로여야 하며 아티팩트 디렉터리는 체크아웃 밖이어야 합니다. 제공된 Playwright 모듈과 실행 가능한 Chromium이 필요합니다. 이 스크립트는 `npm ci`와 `npm test`를 실행하고, 임시 저장 파일을 사용하는 서버에서 HTTP·재시작·브라우저 흐름을 검사합니다. 결과 JSON과 스크린샷은 지정한 아티팩트 디렉터리의 실행별 하위 디렉터리에 남깁니다. 브라우저 시작이나 필수 검사에 실패하면 비정상 종료합니다. 이 문서는 실행하지 않은 검증의 통과를 주장하지 않습니다.

## 운영 범위

이 MVP는 로컬 **단일 사용자·단일 서버 프로세스**를 전제로 합니다. 같은 저장 파일을 여러 프로세스가 동시에 쓰는 운영 방식, 계정, 원격 동기화, 외부 배포, 유료 AI 및 실제 채용 공고 연결은 지원하지 않습니다.
