# Portfolio Project Workspace

이 저장소는 AgentFlow의 실전 개발 흐름을 검증하면서 취업용 포트폴리오 프로젝트를 새로 선정하고 구현하기 위한 작업 공간입니다.

현재 상태는 **초기 기준선**입니다. 과거 Re:Start Quest 구현 브랜치와 실험 Task는 폐기되었으며, 실행 가능한 제품 코드가 있다고 가정하면 안 됩니다.

## 시작 원칙

1. 구현 전에 저장소 전체와 [프로젝트 브리프](docs/PROJECT_BRIEF.md)를 읽습니다.
2. 기존 아이디어를 그대로 확정하지 않고, 사용자 문제와 포트폴리오 경쟁력을 팀 회의에서 다시 검증합니다.
3. 결정된 제품은 하나의 정본 설계와 하나의 통합 브랜치에서 누적합니다.
4. 각 구현 작업은 독립 PR로 검증하되, 완료 판정은 통합 PR의 실제 동작을 기준으로 합니다.
5. 문서, 코드, 테스트, 실행 방법이 같은 revision을 설명해야 합니다.

## 정본 문서

- [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md): 보존할 문제 인식과 새 프로젝트 선정 기준

과거 Task 번호, 작업 브랜치, 후보 SHA, 로컬 AgentFlow 보고서는 정본이 아닙니다.
